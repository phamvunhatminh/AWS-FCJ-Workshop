Now Open — AWS Asia Pacific (New Zealand) Region

By Donnie Prakoso | September 1, 2025 | in Announcements, News, Regions | Permalink | Comments | Share

Audio (Voiced by Amazon Polly)

Kia ora! Today, I’m excited to share that the AWS Asia Pacific (New Zealand) Region is now open, with three Availability Zones and the API name ap‑southeast‑6. With this new Region, customers can run workloads and store data securely in New Zealand while serving end users with even lower latency.

The new AWS Asia Pacific (New Zealand) Region helps organizations run applications and serve end users, while keeping data residency in New Zealand. Amazon Web Services (AWS) is investing NZD 7.5 billion to establish an AWS Region in New Zealand, which is expected to contribute NZD 10.8 billion to New Zealand’s GDP, create an estimated 1,000 new jobs per year, and help organizations of all sizes in New Zealand innovate and scale faster with the most secure and flexible infrastructure.

AWS in New Zealand
Since opening our first office in New Zealand in 2013, we’ve continually expanded our infrastructure to better serve customers in New Zealand:

Connecting to AWS’s global network — In 2016, AWS improved New Zealand’s connectivity to the AWS Global Infrastructure by establishing diverse, high‑capacity submarine cable connections, enhancing reliability and network performance for customers.

Amazon CloudFront — In 2020, AWS expanded local infrastructure by adding two Amazon CloudFront edge locations in Auckland.

AWS Local Zones — To further enhance infrastructure services in New Zealand, AWS introduced an AWS Local Zone in Auckland in 2023, helping customers run applications requiring single‑digit millisecond latency.

AWS Direct Connect — In the same year, AWS added a Direct Connect location in Auckland to help customers securely connect their on‑premises networks to AWS, reducing network costs and improving application performance. With the launch of this Region, AWS is adding another Direct Connect location in Auckland.

Let’s look at how AWS customers are leveraging AWS capabilities to meet diverse needs.

Security and compliance
The New Zealand Government has a cloud‑first policy encouraging cloud adoption across the public sector. AWS supports 143 security and compliance standards and certifications, including PCI DSS, HIPAA, HITECH, FedRAMP, GDPR, FIPS 140‑3, and NIST 800‑171, helping customers meet global compliance requirements and providing a secure cloud infrastructure.

MATTR, a New Zealand‑based organization providing digital trust and infrastructure services to businesses and government, sees significant benefits from the new Region. To learn more about how MATTR and other organizations like Kiwibank and Deloitte plan to use the AWS New Zealand Region, read this news post.

Accelerating AI innovation in New Zealand
AWS offers the most comprehensive set of generative AI capabilities across the stack, including advanced large language models (LLMs) to build generative AI with Amazon Bedrock, and the powerful generative AI assistant Amazon Q that transforms how people work.

Customers in New Zealand are already benefiting from AWS generative AI capabilities.

Thematic is a New Zealand‑based global leader in feedback analytics and customer intelligence. Thematic uses generative AI to turn customer feedback from multiple channels into curated, accurate, and trustworthy customer insights.

“Using Amazon Bedrock is incredibly easy and just makes sense. Whenever we design a solution, we typically test over 10 large language models (LLMs). Consistently, AWS‑provided models win those evaluations,” said Nathan Holmberg, CTO and Co‑founder of Thematic.

To learn about other customers like One NZ leveraging generative AI, read this post.

Building cloud skills together
Since signing a Memorandum of Understanding (MoU) with the New Zealand Government in 2022, Amazon has trained more than 50,000 Kiwis toward a goal of 100,000. Amazon remains committed to investing in cloud education through programs such as AWS Academy, AWS Skills Builder, AWS Educate, and AWS re/Start. Organizations using AWS scale globally while investing in local talent development to meet the growing demand for cloud expertise in New Zealand.

Xero, a global platform for small businesses, helps customers accelerate business growth by integrating essential tools such as accounting, payroll, and payments — all on a single platform. Leveraging AWS since 2016, Xero has scaled its platform globally, improved features, and driven continuous innovation.

“Amazon’s commitment to New Zealand’s technology sector through its NZD 7.5 billion investment is a promising signal. It’s a strong vote of confidence that will connect New Zealand’s technology exporters to new global opportunities across the AWS ecosystem and Amazon’s broader network,” said Bridget Snelling, Xero Country Manager, Aotearoa New Zealand.

Sustainable digital transformation
Through The Climate Pledge, Amazon commits to net‑zero carbon across its business by 2040. AWS also supports New Zealand’s sustainability goals by operating efficient, responsible data centers in the country. The AWS Asia Pacific (New Zealand) Region is supplied with renewable energy from day one under an agreement with Mercury New Zealand.

Energy companies are using AWS to modernize operations while advancing sustainability goals. Sharesies, a financial growth platform, uses AWS to modernize operations while moving toward sustainability.

“Sharesies fully supports storing customer data in‑country and the ability to use renewable energy,” said Richard Clark, CTO of Sharesies. “Doing this in New Zealand on AWS Cloud — fully powered by Mercury’s wind energy — is a huge step forward and incredibly exciting!”

AWS Partners in New Zealand
The AWS Partner Network (APN) in New Zealand is a growing ecosystem of consulting and technology partners helping customers of all sizes design, architect, build, migrate, and manage workloads on AWS. AWS Partners such as Custom D, Grant Thornton Digital, MongoDB, and Parallo are actively supporting customers with innovative solutions tailored to New Zealand organizations’ needs across multiple industries. With the new Region, these partners can now leverage the full power of AWS Cloud services locally.

AWS community in New Zealand
New Zealand is home to 1 AWS Hero, 26 AWS Community Builders, 6 AWS User Groups, and nearly 9,000 community members across AWS User Groups in Auckland, Wellington, and Christchurch. To join AWS User Groups New Zealand, visit their Meetup page and social channels.

AWS Hero Arshad Zackeriya shared this on the new Region:
“The launch of an AWS Region in New Zealand is a major milestone. It’s not just a new set of data centers; it unlocks potential for New Zealand businesses and the developer community, enabling us to build a better, more connected Aotearoa for everyone.”

Now available
AWS Asia Pacific (New Zealand) Region is New Zealand’s first AWS infrastructure Region and the sixteenth in Asia Pacific. With this launch, AWS now has 120 Availability Zones across 38 geographic Regions worldwide, with plans for 10 more AZs and 3 new AWS Regions in Saudi Arabia, Chile, and European Sovereign Cloud.

The new Asia Pacific (New Zealand) Region is ready to support your business. See the list of available services in this Region at AWS Services by Region.
Learn more at AWS Global Infrastructure and start building on ap‑southeast‑6!

Happy building!
