### Week 2 Objectives:

* Learn about AWS Support and support plans
* Learn about AWS Identity and Access Management (IAM)
* How to access and create support cases in AWS Support
* Set up a basic IAM admin structure (Groups, Policies, Users)
* Implement advanced security with IAM Roles
* Learn how to grant application access:
  * How to grant access via Access Key/Secret Access Key and why it should be avoided
  * How to grant access via IAM Role on EC2

  * Understood AWS Support and the different plans (Basic, Developer, Business, Enterprise)
  * Learned how to access AWS Support from the AWS Management Console
  * Understood the process for creating a Support Case

* Tuesday (16/09/2025):
