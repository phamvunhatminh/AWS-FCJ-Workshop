### Kết quả đạt được tuần 4:

* **Thứ 2 (29/09/2025):**
  * Hiểu AWS Cloud9 là một môi trường phát triển tích hợp (IDE) hoạt động trên trình duyệt web
  * Nắm rõ các tính năng của Cloud9:
    * Chỉnh sửa mã với hỗ trợ nhiều ngôn ngữ lập trình
    * Runtime debugger
    * Terminal tích hợp
    * Build, chạy, kiểm tra và gỡ lỗi phần mềm

* **Thứ 3 (30/09/2025):**
  * Hiểu Amazon S3 là dịch vụ lưu trữ đối tượng (Object Storage)
  * Nắm rõ các use case của S3:
    * Kho dữ liệu (data warehouse)
    * Trang web tĩnh
    * Ứng dụng di động
    * Sao lưu và khôi phục
    * Lưu trữ dữ liệu
    * Ứng dụng doanh nghiệp
    * Thiết bị IoT
    * Phân tích dữ liệu lớn
  * Biết rằng S3 được thiết kế để đảm bảo độ bền 99.999999999% (11 9's)
  * Thực hành tạo S3 Bucket

* **Thứ 4 (01/10/2025):**
  * Cấu hình Cloud9 IDE theo sở thích cá nhân:
    * Thay đổi chủ đề màu sắc
    * Liên kết các phím tắt
    * Cài đặt định dạng mã
    * Tô màu cú pháp dành riêng cho ngôn ngữ

* **Thứ 5 (02-03/10/2025):**
  * Thao tác cơ bản khi làm việc với Cloud9:
    * Viết mã trong Cloud9
    * Sử dụng terminal tích hợp
    * Debug code
    * Upload file lên S3 từ Cloud9
  * Hiểu các trường hợp sử dụng S3 trong các dự án

* **Thứ 6 (03/10/2025):**
  * Tạo Project trong Cloud9 và viết code mẫu
  * Kiểm tra code và gỡ lỗi trong Cloud9
  * Tạo S3 Bucket cho dự án
  * Upload dữ liệu lên S3
  * Cấu hình quyền truy cập và quản lý dữ liệu trong S3
  * Tích hợp Cloud9 với S3 cho quy trình phát triển ứng dụng
