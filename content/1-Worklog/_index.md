**On this page**, you will need to introduce your worklog. **How** did you complete it? How many weeks did you take to complete the program? **What** did you do in those weeks?

Typically, and as a standard, a worklog is carried out over about 3 months (throughout the internship period). Below is a 12‑week summary with links to details:

**Week 1:** [Getting familiar with AWS and core services](1.1-week1/)

**Week 2:** [AWS Support and IAM fundamentals (Users, Groups, Roles, Policies)](1.2-week2/)

**Week 3:** [VPC design, Site‑to‑Site VPN, EC2 basics, deploy Node.js app](1.3-week3/)

**Week 4:** [AWS Cloud9 IDE and Amazon S3 with hands‑on](1.4-week4/)

**Week 5:** [Amazon RDS: engines, security, Multi‑AZ, Read Replicas, snapshots](1.5-week5/)

**Week 6:** [Auto Scaling + Load Balancer + CloudWatch (end‑to‑end)](1.6-week6/)

**Week 7:** [Amazon Route 53 hybrid DNS and AWS CLI practice](1.7-week7/)

**Week 8:** [DynamoDB with Python, ElastiCache (Redis), CloudFront on S3](1.8-week8/)

**Week 9:** [Project kickoff: BMR/TDEE/MET/PF and AWS architecture](1.9-week9/)

**Week 10:** [Mediapipe pose detection, React + TypeScript UI, Bedrock Q&A](1.10-week10/)

**Week 11:** [13‑service AWS architecture, deployment plan, cost estimate](1.11-week11/)

**Week 12:** [Finalize, test, optimize, deploy, and demo](1.12-week12/)
