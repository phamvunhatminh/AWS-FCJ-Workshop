### Mục tiêu tuần 3:

* Khám phá và thực hành với Amazon Virtual Private Cloud (VPC)
* Thiết kế, triển khai và quản lý môi trường mạng riêng tư trên AWS Cloud
* Thiết lập kết nối Site-to-Site VPN an toàn giữa cơ sở hạ tầng tại chỗ và AWS Cloud
* Học cách khởi tạo và tìm hiểu các tính năng cơ bản của Amazon EC2
* Triển khai ứng dụng AWS User Management (Node.js) trên EC2

### Kết quả đạt được tuần 3:

* **Thứ 2 (22/09/2025):**
  * Hiểu rõ về Amazon Virtual Private Cloud (VPC) và tầm quan trọng của nó
  * Tìm hiểu về Amazon EC2 - dịch vụ Elastic Compute Cloud
  * Hiểu khái niệm về AWS User Management Application (ứng dụng CRUD Node.js)

* **Thứ 3 (23/09/2025):**
  * Thiết kế VPC theo tiêu chuẩn AWS Well-Architected Framework
  * Cấu hình các thành phần bảo mật mạng quan trọng:
    * Network ACLs (Access Control Lists)
    * Security Groups
    * Subnet segmentation (phân đoạn mạng)
  * Thực hành tạo VPC với các subnets

* **Thứ 4 (24/09/2025):**
  * Thiết lập kết nối Site-to-Site VPN an toàn
  * Hiểu cách mã hóa dữ liệu trong quá trình truyền tải
  * Cấu hình kết nối an toàn giữa on-premise và AWS Cloud
  * Thực hành cài đặt VPN Connection

* **Thứ 5 (25/09/2025):**
  * Hiểu các EC2 Instance types khác nhau
  * Tìm hiểu về Amazon Machine Image (AMI)
  * Cấu hình Security Groups cho EC2
  * Nắm rõ cách kết nối tới EC2 (SSH cho Linux, RDP cho Windows)

* **Thứ 6 (26/09/2025):**
  * Thực hành tạo EC2 instances (cả Windows Server 2022 và Amazon Linux 2)
  * Kết nối tới EC2 thông qua SSH (Linux) và RDP (Windows)
  * Cài đặt AWS User Management Application (Node.js)
  * Kiểm tra các tính năng CRUD hoạt động (thêm, xóa, sửa, tìm kiếm người dùng)
  * Chia sẻ ứng dụng cho tất cả người dùng khác
