### Week 3 Objectives:

* Explore and practice with Amazon Virtual Private Cloud (VPC)
* Design, deploy, and manage a private network environment on AWS Cloud
* Establish a secure Site-to-Site VPN between on-premises and AWS Cloud
* Learn how to launch and understand Amazon EC2 basics
* Deploy the AWS User Management application (Node.js) on EC2
